# Selenium TestNG Framework

A Java-based UI test automation framework built with Selenium WebDriver and TestNG, following the **Page Object Model (POM)** design pattern. Designed to support multi-browser, parallel test execution out of the box.

## Project Overview

This framework automates end-to-end UI testing for [Swag Labs](https://www.saucedemo.com/) using the following stack:

| Technology | Purpose |
|---|---|
| Java 17 | Core programming language |
| Selenium WebDriver | Browser automation |
| TestNG | Test execution and assertions |
| Maven 3.x | Build and dependency management |
| WebDriverManager | Automatic browser driver management |
| ExtentReports | HTML test reporting |

**Key Design Decisions:**
- **Page Object Model (POM)** — each page is represented as a class, keeping test logic separate from UI interactions
- **Abstract `Page` class** — defines a contract of common page actions (`getElement`, `waitForElement`, etc.)
- **`BasePage`** — concrete implementation of `Page`, shared across all page classes
- **Utility classes** — dedicated `utils` package for config reading, data provision, reporting, and screenshots

## Prerequisites & Setup

### 1. Install Required Tools

| Tool | Version | Download |
|---|---|---|
| Java JDK | 17 | https://adoptium.net |
| Maven | 3.x | https://maven.apache.org |
| Google Chrome | Latest | https://www.google.com/chrome |
| Mozilla Firefox | Latest | https://www.mozilla.org/firefox |

### 2. Verify Installations

```bash
java -version
# Expected: openjdk version "17.x.x"

mvn -version
# Expected: Apache Maven 3.x.x
```

### 3. Clone the Repository

```bash
git clone <your-repository-url>
cd UIFrameworkPOM
```

### 4. Install Dependencies

```bash
mvn clean install -DskipTests
```

> WebDriverManager automatically downloads the correct ChromeDriver and GeckoDriver — no manual driver setup needed.

### Key Files Explained

**`Page.java`** — Abstract class that all page objects extend. Holds `WebDriver` and `WebDriverWait` instances and defines abstract methods every page must implement.

**`BasePage.java`** — Implements all abstract methods from `Page`. Contains the `getInstance()` factory method used to create page object instances.

**`HomePage.java`** — Page Object representing the post-login home/inventory page.

**`LoginPage.java`** — Page Object representing the Swag Labs login page with login action methods.

**`ConfigReader.java`** — Reads key-value pairs from `config/config.properties` for environment-level configuration such as base URL and credentials.

**`DataProviderUtil.java`** — Supplies parameterised test data to TestNG `@DataProvider` methods, sourcing values from JSON files via `JsonReader`.

**`ExtentManager.java`** — Manages the ExtentReports instance lifecycle — initialises the report at suite start and flushes it on completion.

**`JsonReader.java`** — Parses `testdata/loginData.json` and returns test data as structured objects for data-driven tests.

**`ScreenshotUtil.java`** — Captures a screenshot of the current browser state, typically invoked on test failure via `TestListener`.

**`BaseTest.java`** — Parent class for all test classes. Handles browser initialisation via `@BeforeMethod` and teardown via `@AfterMethod`. Uses `ThreadLocal<WebDriver>` for parallel safety.

**`LoginTest.java`** — Contains all login test cases, exercising valid credentials, invalid credentials, and edge-case scenarios.

**`TestListener.java`** — Implements `ITestListener` to hook into TestNG events — captures screenshots on failure and logs results to ExtentReports.

**`config.properties`** — Centralised configuration file for base URL, default browser, and any environment-specific properties.

**`loginData.json`** — JSON file holding credential sets and expected outcomes used by `DataProviderUtil` for data-driven login tests.

**`testng.xml`** — Defines the test suite, parallel execution mode, thread count, and browser parameters passed to `BaseTest`.

## How to Run Tests

### Run Full Suite (Both Browsers in Parallel)

```bash
mvn test
```

### Run a Specific Test Class

```bash
mvn test -Dtest=LoginTest
```

### Run with a Specific Browser Only

```bash
mvn test -Dbrowser=chrome
# or
mvn test -Dbrowser=firefox
```

### Skip Tests During Build

```bash
mvn clean install -DskipTests
```

> Test reports are generated at `target/surefire-reports/index.html` and `target/extent-reports/` after each run.

## Configuration

### Browser & Parallel Setup — `testng.xml`

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE suite SYSTEM "http://testng.org/testng-1.0.dtd">

<suite thread-count="2" name="Swag Labs Test Automation Suite" parallel="tests" verbose="5">

    <listeners>
        <listener class-name="tests.TestListener" />
    </listeners>

    <test name="Chrome Tests">
        <parameter name="browser" value="chrome" />
        <classes>
            <class name="tests.LoginTest" />
        </classes>
    </test>

    <test name="Firefox Tests">
        <parameter name="browser" value="firefox" />
        <classes>
            <class name="tests.LoginTest" />
        </classes>
    </test>

</suite>
```

### Configuration Reference

| Parameter | Location | Options | Default |
|---|---|---|---|
| `browser` | `testng.xml` / `config.properties` | `chrome`, `firefox` | `chrome` |
| `thread-count` | `testng.xml` | Any integer | `2` |
| `parallel` | `testng.xml` | `tests`, `methods`, `classes` | `tests` |
| `baseUrl` | `config.properties` | Any valid URL | `https://www.saucedemo.com` |

### Maven Surefire Plugin — `pom.xml`

Ensure your `pom.xml` points to the `testng.xml` file:

```xml
<build>
    <plugins>
        <plugin>
            <groupId>org.apache.maven.plugins</groupId>
            <artifactId>maven-surefire-plugin</artifactId>
            <version>3.0.0</version>
            <configuration>
                <suiteXmlFiles>
                    <suiteXmlFile>src/test/resources/testng.xml</suiteXmlFile>
                </suiteXmlFiles>
            </configuration>
        </plugin>
    </plugins>
</build>
```

### Adding a New Browser

1. Add a new `<test>` block in `testng.xml` with the browser parameter
2. Add the corresponding driver setup in `BaseTest.java`:

```java
} else if (browser.equals("edge")) {
    WebDriverManager.edgedriver().setup();
    driver = new EdgeDriver();
}
```
